# Translations

`i18n.ts` loads texts from JSON **bundles**, one per language and part of the app, and hands them out
by key.

```ts
import { setCurrentLanguage, loadTextBundle, getText } from "./gtd/i18n.js"
```

## Files

Bundles live under `./i18n/<language>/<bundle>.json`, relative to the page:

```
i18n/
├── en/
│   └── home.json   {"title": "Welcome", "logout": "Log out"}
└── es/
    └── home.json   {"title": "Bienvenida", "logout": "Salir"}
```

## Using it

```ts
await setCurrentLanguage(navigator.language) // "es-ES" → Spanish
await loadTextBundle("home")

title.textContent = getText("home", "title")
```

- `loadTextBundle(id)` does nothing if the bundle is already loaded. Load each bundle once, before
  the views that need it.
- `getText(bundle, key)` returns `""` for a bundle that is not loaded or a key that is missing, so
  the page never shows `undefined`.

## Changing language at runtime

```ts
await setCurrentLanguage("en", true) // true: load again every bundle already loaded
showRoute(currentPath, app)          // draw again with the new texts
```

## Languages

The module ships `Languages.English`, `Languages.Spanish` and `Languages.Galician`. A locale is
matched against each language's `locales`; anything unknown falls back to English with a warning.

To add one, edit the top of `i18n.ts`:

```ts
export const Languages = {
  // …
  Basque: { name: "basque", main: "eu", locales: ["eu", "eu-ES"] },
}

const AVAILABLE_LANGUAGES = [Languages.English, Languages.Spanish, Languages.Basque]
```

`main` is the folder name under `i18n/`. Only languages in `AVAILABLE_LANGUAGES` can be chosen.

## Failures

`loadTextBundle(id, reload, maxAttempts)` tries up to `maxAttempts` times (one by default). A bundle
that cannot be fetched or parsed is skipped quietly, and its texts read as `""`.
